Git 身份,一键切换

本地 Git 配置切换工具。多套身份(工作 / 个人 / 开源)一键切换、 按目录自动加载、配置浏览器、备份回滚 —— 告别手改 ~/.gitconfig 的日子。

最新版本 v0.1.0 · 纯本地运行,配置不出本机 · 写前自动备份,全程可回滚

核心功能

为经常切换 Git 身份的开发者打造,每一个写操作都有备份兜底。

多身份配置集

工作 / 个人 / 开源多套身份 CRUD,常用项模板(签名密钥、代理等),一键应用到全局或指定仓库。

按目录自动切换

目录 → 配置集映射(includeIf),进入 D:/work 自动加载工作身份,冲突检测 + 一键同步。

配置浏览器

浏览全部配置项,标注 system / global / local 来源,敏感项默认脱敏,悬停查看配置含义。

备份与回滚

每次写操作前自动备份,备份点列表、行级 Diff、一键回滚,回滚前再保护 —— 全程可逆。

导入导出

配置集导出 JSON / 剪贴板,敏感项可选脱敏,换机迁移一键完成。

系统托盘

托盘一键应用配置集,全局身份实时显示;关闭窗口最小化到托盘,不打断工作流。

典型场景

身兼多职的开发者,再也不用记着切换身份。

工作仓库

公司邮箱 + 提交签名密钥 + 公司代理。进入工作目录自动生效,commit 永远署名正确。

user.email = work@company.com user.signingkey = 4A5B…

个人项目

私人邮箱与 GPG 签名,和公司配置完全隔离,互不污染。

user.email = me@home.dev commit.gpgsign = true

开源贡献

开源仓库用独立身份,避免把个人邮箱写进公开提交记录。

user.email = oss@github.dev user.name = my-bot-name

深色玻璃拟态设计,主题 / 语言跟随系统。

快速开始

四步完成身份切换,全程 GUI 操作。

下载安装

从 Releases 下载安装包,双击安装;依赖 Git for Windows,首次启动自动检测。

创建配置集

引导自动预填当前全局身份;再为工作、个人分别建一套配置集。

一键应用

全局或仓库级应用:覆盖同名项 + 保留无关项,写前自动备份。

目录自动切换

把目录映射到配置集,进入目录即生效;改坏了随时回滚。
